# Frontend & UI Skills

When work involves frontend, UI, or component changes, additionally apply:

- `vercel-react-best-practices` — performance patterns, proper data fetching, bundle optimization
- `vercel-composition-patterns` — component composition over configuration, avoid boolean prop proliferation, use compound components
- `interface-design` — build with craft, consistency, and design system alignment

This applies to both implementation and review — whether writing new UI code, reviewing a plan that includes UI work, or auditing existing frontend changes.
