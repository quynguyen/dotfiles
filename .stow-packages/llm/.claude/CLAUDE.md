# Browsing

Use the `/browse` skill from gstack for all web browsing. Never use `mcp__claude-in-chrome__*` tools.

# Priorities

If the project has `docs/priorities.md`, append demand signals to its Maslow's Inbox (minbox) section as `- I need/want/wish: [observation] (because [reason])` when I express frustration, a wish, or find something broken. Inline, no ceremony. Errors and feedback count as signals.

# Writing

Prose, not telegraphic fragments. Avoid formats like "Default: X. Why: Y. Alternative: Z." — the labels save words but shift the work of reconstructing sentences onto me. One sentence per option, connected by "because" and "but", beats five labeled bullets.
